# docs/dev — archived development history

These are **internal development reports, plans, audits, and benchmark write-ups**
accumulated while building TissueResolve. They are kept for provenance and
reproducibility but are **not** part of the public/user-facing documentation.

Nothing here is required to use TissueResolve. They include negative-result reports
(state-regularization, combined smoothing, etc.) that are deliberately preserved —
they document where the tool correctly declines to promise non-identifiable fine
resolution.

**Public / user-facing documentation lives one level up in [`docs/`](../):**

- Usage: `quickstart.md`, `tutorial.md`, `input_formats.md`, `advanced_parameters.md`,
  `reporting.md`, `output_interpretation.md`, `benchmarking.md`,
  `normalization_and_protocols.md`, `batch_effects.md`, `library_type_references.md`,
  `qc_thresholds.md`
- Status & method: `FEATURE_STATUS.md`, `PERFORMANCE_BENCHMARK_REPORT.md`,
  `POISSON_GLM_RECOMMENDED_SOLVER.md`, `NB_BULK_SOLVER_REPORT.md`
- Alpha: `ALPHA_RELEASE_NOTES.md`, `ALPHA_RELEASE_CHECKLIST.md`,
  `FUTURE_WORK_DISTRIBUTION_AWARE_REFERENCE.md`
- Tutorials: `docs/tutorials/`; figures/tables: `docs/figures/`
